# Поймай удачу

Мобильная демоверсия по Figma, файл mw00XVEFGB9IAc9zdVd50q, фрейм 121:3003. Исходная графика экспортирована из отдельных слоёв, попап повторяет оформление 121:3122. Временные экспортные копии в Figma удалены, исходные слои сохранены.

Откройте `dist/index.html` через статический HTTP-сервер. Например: `python3 -m http.server 8080 --directory dist`.

- 60 секунд активной игры; открытие правил и наград ставит игру на паузу.
- Перетаскивание начинается только с капибары; после отпускания требуется повторный захват персонажа. Сохраняется смещение пальца при захвате.
- Три вертикальные колонки соответствуют сетке исходного экрана. В первые 10 секунд одновременно падает только один предмет; затем скорость и частота увеличиваются каждые 10 секунд.
- Каждый пойманный предмет даёт одну монету, пропуски не штрафуются.
- Пороги наград: 20, 30, 40. Прогресс сбрасывается на 20 и 30; после 40 остаётся полным, счёт продолжает расти.
- Передний слой мешка скрывает пойманный предмет; ветка и сугроб перекрывают персонажа слева.
- Праздничный эффект поимки: лёгкое пружинящее движение без прыжка и наклонов, золотое свечение и кольцо, звёзды, снежинки, красно-зелёное конфетти, золотистая плашка «+1» с плавным появлением и монета, летящая к счётчику. Награда усиливает эффект. При снижении движения в настройках устройства остаётся короткая плашка без частиц и прыжков.
- Итоговый попап — заглушка с фактическими результатами и перезапуском. Карточки наград без реальной выдачи призов.
- Новогодняя иллюстрация итогового попапа сгенерирована на основе оригинального персонажа: капибара в праздничной шапке с подарками, ёлочными шарами и еловыми ветками.

Проверка логики: `node --test tests/game-core.test.mjs`.
