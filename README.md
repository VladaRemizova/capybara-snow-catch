# Capybara Snow Catch

Мобильная зимняя игра: управляйте капибарой, ловите предметы открытым мешком, собирайте монеты и награды за 60 секунд.

## Запуск

Нужен Node.js 24 (или новее).

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:8080. На компьютере показывается тот же мобильный экран; управление поддерживает мышь и касания.

## Файлы проекта

- `dist/index.html` — разметка игрового экрана.
- `dist/main.mjs` — управление, отображение и анимации.
- `dist/game-core.mjs` — движение, ловля, таймер и правила наград.
- `dist/styles.css` — оформление экрана и эффектов.
- `dist/assets/` — изображения персонажа, предметов и фона.
- `tests/` — проверки игровой логики и жестов.

Сборка не требуется: папка `dist/` готова для любого статического хостинга.

## Проверки

```sh
npm test
npm run check
```

Для проверки в браузере:

```sh
npx playwright install chromium
npm run dev
# В другом терминале:
npm run test:browser
```

При необходимости можно указать установленный Chromium через `CAPY_CHROMIUM_PATH`.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации. При отправке изменений в `main` workflow проверит код и опубликует содержимое `dist/`. Ссылка появится в разделе Pages и в результате workflow.

Доступность Pages для закрытого репозитория зависит от тарифа GitHub. Сам проект можно разместить и на другом статическом хостинге.

## Механика

- 60 секунд активной игры; открытие правил и наград ставит игру на паузу.
- Перетаскивание начинается только с капибары; после отпускания требуется повторный захват персонажа. Сохраняется смещение пальца при захвате.
- Три позы из Figma 132:3626 / 132:3625 / 132:3627: при движении мешок закрыт, взгляд направлен вверх-влево или вверх-вправо; после остановки или отпускания — взгляд вверх и открытый мешок. Стационарное удержание пальца тоже открывает мешок. Остановка определяется за 40 мс, открытая поза появляется сразу без ожидания анимации; закрытие и разворот занимают 20 мс. Зона смены позы и разворота — 8 пикселей, мелкие корректировки позиции внутри неё не закрывают мешок.
- Предмет засчитывается только если мешок был открыт в момент пересечения его края. Предмет, пропущенный с закрытым мешком, нельзя поймать задним числом при открытии.
- Три вертикальные колонки соответствуют сетке исходного экрана. В первые 10 секунд одновременно падает только один предмет; затем скорость и частота увеличиваются каждые 10 секунд.
- Каждый пойманный предмет даёт одну монету, пропуски не штрафуются.
- Пороги наград: 20, 30, 40. Прогресс сбрасывается на 20 и 30; после 40 остаётся полным, счёт продолжает расти.
- Передний слой мешка скрывает пойманный предмет; ветка и сугроб перекрывают персонажа слева.
- Праздничный эффект поимки: лёгкое пружинящее движение без прыжка и наклонов, золотое свечение и кольцо, звёзды, снежинки, красно-зелёное конфетти, золотистая плашка «+1» с плавным появлением и монета, летящая к счётчику. Награда усиливает эффект. При снижении движения в настройках устройства остаётся короткая плашка без частиц и прыжков.
- Итоговый попап — заглушка с фактическими результатами и перезапуском. Карточки наград без реальной выдачи призов.
- Новогодняя иллюстрация итогового попапа сгенерирована на основе оригинального персонажа: капибара в праздничной шапке с подарками, ёлочными шарами и еловыми ветками.
