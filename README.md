# Capybara Snow Catch

Мобильная интерактивная демоверсия по Figma, файл `mw00XVEFGB9IAc9zdVd50q`. Отдельные графические слои экспортированы в локальные PNG; временные URL Figma в игре не используются.

Запуск: `npm ci`, затем `npm run dev` (Node.js 24). Игра доступна на http://127.0.0.1:8080.

Для браузерных проверок: `npx playwright install chromium`, затем `npm run test:browser`. Для системного Chromium укажите переменную `CAPY_CHROMIUM_PATH`.

Автопубликация подготовлена в `.github/workflows/pages.yml`: включите GitHub Pages → Source → GitHub Actions. Доступность Pages для приватного репозитория зависит от тарифа GitHub.

- Игра начинается с экрана обучения `146:6374`. Круг делает два прохода внутри скруглённой дорожки, затем затемнение исчезает и начинается отсчёт 60 секунд. Кнопки запуска и прежней текстовой подсказки нет.
- Перетаскивание начинается только с капибары; после отпускания требуется повторный захват. Смещение пальца сохраняется.
- Мешок всегда открыт, предметы ловятся при движении и остановке. Голова поворачивается вверх-влево/вверх-вправо при перемещении, после остановки смотрит вверх. Зона смены направления — 8 логических пикселей; остановка определяется за 40 мс.
- Две серии персонажа переключаются небольшой кнопкой справа по центру. Выбор сохраняется при перезапуске текущей страницы.
- Предметы падают строго вертикально по трём колонкам. Первые 10 секунд падает один предмет, затем постепенно растут скорость и частота. Сообщение об ускорении не показывается.
- Каждый пойманный предмет даёт одну монету. Пропуски без штрафа. Монеты продолжают накапливаться после 40.
- Награды выдаются при 20, 30 и 40 монетах, максимум три за раунд. Прогресс обнуляется на 20 и 30.
- Каждая награда вызывает экран `146:6225` ровно на 3 секунды, включая появление и закрытие. Таймер и предметы полностью на паузе. Графика растёт из центра, оригинальные конфетти разлетаются от значка; закрытие уменьшает всю композицию.
- Окно результатов повторяет `146:6657`: оригинальная капибара с монетами, фактический счёт и награды, перезапуск. Коммерческая выдача и открытие призов остаются демонстрационными.
- Ветка и сугроб перекрывают персонажа слева, передний край мешка закрывает пойманный предмет.
- При поимке сохранены мягкая деформация, золотая плашка +1, снежинки и монета, летящая в счётчик. Настройка уменьшения движения убирает интенсивные эффекты.
